# 📘 Hypertext in HTML

This repository explains what **Hypertext** is in the context of HTML with a simple example.

---

## 📄 What is Hypertext?

**Hypertext** is text displayed on a computer or web page that contains links (hyperlinks) to other text or resources.

In HTML, **hypertext** is created using the `<a>` (anchor) tag, where the **text you click** is the **hypertext**.

---

## ✅ HTML Example of Hypertext

Example html code
<!DOCTYPE html>
<html>
<head>
  <title>Hypertext Example</title>
</head>
<body>
  <h1>Example of Hypertext in HTML</h1>
  <p>
    Learn more about web development by visiting
    <a href="https://developer.mozilla.org">MDN Web Docs</a>.
  </p>
</body>
</html>
